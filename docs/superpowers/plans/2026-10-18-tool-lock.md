# Tool Lock File Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `cyberfw init` installs exactly the tool releases pinned in a committed `tools.lock` and refuses any archive whose SHA-256 differs; `cyberfw lock [--upgrade]` is the only way pins move.

**Architecture:** A new `cyberfw/manager/lock.py` owns the lock file (pydantic models, deterministic YAML I/O) and resolution (release → per-platform asset via a shared `select_asset()` → hash from GitHub's API digest / `checksums.txt` / a hashing download). `ToolManager.install` reads its entry (adding a missing one), and `ToolInstaller.install_locked` downloads the locked URL and verifies the hash before touching the previous install. The CLI gains `cyberfw lock`; `registry.yaml` loses `sha256:` / `needs_checksum:`.

**Tech Stack:** Python 3.14 via `uv`, pydantic v2, PyYAML, httpx, Typer + Rich, pytest, ruff, mypy `--strict`.

**Spec:** `docs/superpowers/specs/2026-10-18-tool-lock-design.md`

## Global Constraints

- Run everything through `uv run --quiet …` (the bare interpreter lacks `prompt_toolkit`): tests `uv run --quiet python -m pytest -q`, lint `uv run --quiet ruff check cyberfw tests`, types `uv run --quiet mypy cyberfw`. All three clean at the end of every task.
- Tests never touch the network.
- Lock file name `tools.lock`, file format `version: 1`. Platforms exactly, in this order: `linux/amd64`, `linux/arm64`, `darwin/amd64`, `darwin/arm64`, `windows/amd64`. Hash `source` ∈ `digest` | `checksums` | `download`. URLs must be `https://`; `sha256` is 64 lowercase hex.
- Error texts (from the spec): `SHA-256 mismatch for <asset>: tools.lock has <x>, got <y>` · `tools.lock is out of date for <tool>: <reason> — run \`cyberfw lock\`` · `<tool> <tag> has no locked asset for <os/arch>` · `cannot write <path>: … — run cyberfw from a workspace (a directory with registry.yaml) to change pins` · `digest and checksums.txt disagree for <asset>`.
- Commits: **no `Co-Authored-By` trailer** (the user's standing rule for this repo). Write multi-line messages to a file in the session scratchpad and use `git commit -F <file>`. Stage only the task's files — never `CS-TOOL_presentation.pdf`.
- Scratchpad (for commit messages and build output): `SCRATCH=C:/Users/DANIIL~1/AppData/Local/Temp/claude/C--Users-DaniilSirbu-Desktop-CS-TOOL-main/6a8b772a-7993-414c-98b5-45500cbb762c/scratchpad`.
- Do **not** add `tools.lock` to `pyproject.toml`'s force-include before Task 9: hatchling fails the build on a missing forced include, which breaks `uv run`.
- Windows checkout: working tree CRLF, index LF (autocrlf). `write_lock` writes LF.

## Review Focus

1. `cyberfw lock --upgrade` meets the same tag with a different file (upstream replaced a published asset) → the tool is reported failed and its old entry kept, never silently re-pinned. Test: Task 6 `test_upgrade_refuses_a_changed_file_under_the_same_tag`.
2. cyberfw runs outside the checkout (the user's `uv tool install --editable .` resolves the registry next to the package, not in the CWD), including with `--token` → the lock is read and written next to *that* registry. Test: Task 8 `test_the_lock_lives_next_to_the_registry_in_use`.
3. A `tools.lock` left with git merge-conflict markers → a `LockError` naming the file, not a traceback. Test: Task 3, `merge-conflict` case.
4. A release whose checksums file lists SHA-512 digests → treated as "no checksum" and hashed by download, never stored as a bogus hash. Test: Task 4 `test_a_sha512_checksums_file_counts_as_no_checksum`.
5. The lock location is not writable (a wheel's packaged copy) or the write is interrupted → `LockError` that says to use a workspace, the old file intact, no `.tmp` left. Test: Task 3 `test_an_unwritable_location_is_a_lock_error_and_keeps_the_old_file`.

_SHA256_HEX = re.compile(r"[0-9a-f]{64}")


def _sha256_digest(value: object) -> str | None:
    """``"sha256:<hex>"`` → lowercase ``<hex>``; another algorithm or shape → ``None``."""
    if not isinstance(value, str):
        return None
    algorithm, _, hexdigest = value.partition(":")
    hexdigest = hexdigest.strip().lower()
    if algorithm.strip().lower() != "sha256" or not _SHA256_HEX.fullmatch(hexdigest):

    return hexdigest

```python
def _os_patterns(spec: ToolSpec, mapping: Mapping) -> list[str]:
    """The registry patterns that name ``mapping``'s OS (``macos`` counts as darwin)."""
    os_tokens = {mapping.os_name}
    if mapping.os_name == "darwin":
        os_tokens.add("macos")
    return [pattern for pattern in spec.asset_patterns if any(token in pattern.lower() for token in os_tokens)]


def select_asset(release: GitHubRelease, spec: ToolSpec, mapping: Mapping) -> ReleaseAsset | None:
    """The asset of ``release`` that ``spec`` installs on ``mapping``'s platform, or ``None``.

    The platform's own spellings come first (without the bare ``*windows*``
    catch-all), then the registry patterns naming this OS, and only then the
    catch-all. Registry patterns for *other* OSes are never eligible: a Linux
    build must never be picked as a fallback on macOS just because it is listed
    first. Shared by the installer and ``tools.lock`` so they cannot disagree.
    """
    platform_patterns = asset_patterns(mapping)
    exact = [pattern for pattern in platform_patterns if pattern != "*windows*"]
    asset = release.find_asset(*exact)
    if asset is None:
        os_patterns = _os_patterns(spec, mapping)
        if os_patterns:
            asset = release.find_asset(*os_patterns)
    if asset is None:
        asset = release.find_asset(*platform_patterns)
    return asset
```

Create `cyberfw/manager/lock.py`:

```python
"""tools.lock — every downloaded tool pinned to one release and verified by hash.

``registry.yaml`` is the intent: which tools, from where, optionally which
``version:``. ``tools.lock`` is the resolved state: the exact release tag of each
tool and the SHA-256 of its asset on every supported platform. ``cyberfw init``
installs exactly what it pins and refuses an archive whose hash differs;
``cyberfw lock`` is the only writer. The file is committed next to the registry
it pins, so every machine installs byte-identical tools.
"""

from __future__ import annotations

import contextlib
import os
import re
from pathlib import Path
from typing import Literal

import yaml
from pydantic import BaseModel, ConfigDict, Field, ValidationError, field_validator

from cyberfw.exceptions import LockError
from cyberfw.manager.platform_map import SUPPORTED_PLATFORMS

__all__ = [
    "LOCK_FORMAT",
    "LOCK_NAME",
    "HashSource",
    "LockedAsset",
    "LockedTool",
    "ToolLock",
    "dump_lock",
    "read_lock",
    "write_lock",
]

#: The lock's file name; it lives next to the ``registry.yaml`` it pins.
LOCK_NAME = "tools.lock"
#: The file-format version this cyberfw writes and reads.
LOCK_FORMAT = 1

#: Where a locked hash came from: the GitHub API's asset digest, the release's
#: own checksums file, or hashing the downloaded asset at lock time.
HashSource = Literal["digest", "checksums", "download"]

_HEADER = (
    "# tools.lock — generated by `cyberfw lock`; do not edit by hand.\n"
    "# Pins every downloaded tool to one release and the SHA-256 of each platform's\n"
    "# asset. `cyberfw init` installs exactly these and refuses an archive whose hash\n"
    "# differs. Change pins with `cyberfw lock [--upgrade] [tool ...]` and commit.\n"
)

_SHA256 = re.compile(r"[0-9a-f]{64}")


class LockedAsset(BaseModel):
    """One platform's asset of a locked release."""

    model_config = ConfigDict(extra="forbid")

    name: str
    url: str
    sha256: str
    source: HashSource

    @field_validator("url")
    @classmethod
    def _https(cls, value: str) -> str:
        if not value.startswith("https://"):
            raise ValueError(f"must be an https:// URL, got {value!r}")
        return value

    @field_validator("sha256")
    @classmethod
    def _hex(cls, value: str) -> str:
        if not _SHA256.fullmatch(value):
            raise ValueError("must be 64 lowercase hex characters")
        return value


class LockedTool(BaseModel):
    """One tool pinned to a release: its repo, tag and asset per platform."""

    model_config = ConfigDict(extra="forbid")

    repo: str
    tag: str
    #: ``Mapping.label`` (``"linux/amd64"``) → that platform's asset.
    assets: dict[str, LockedAsset]

    @property
    def version(self) -> str:
        """``1.2.3`` for tag ``v1.2.3`` — the form the install state records."""
        return self.tag.lstrip("vV")


class ToolLock(BaseModel):
    """The whole ``tools.lock`` document."""

    model_config = ConfigDict(extra="forbid")

    version: int = LOCK_FORMAT
    tools: dict[str, LockedTool] = Field(default_factory=dict)

    @field_validator("version")
    @classmethod
    def _known_format(cls, value: int) -> int:
        if value != LOCK_FORMAT:
            raise ValueError(f"unsupported lock format {value} (this cyberfw reads {LOCK_FORMAT})")
        return value


def read_lock(path: Path) -> ToolLock | None:
    """Parse ``path``; ``None`` when there is no such file.

    Anything malformed — YAML, schema, a hash or URL, an unknown format
    version, leftover merge-conflict markers — is a :class:`LockError` naming
    the file.
    """
    if not path.is_file():
        return None
    try:
        document = yaml.safe_load(path.read_text(encoding="utf-8"))
    except (OSError, yaml.YAMLError) as exc:
        raise LockError(f"cannot read {path}: {exc}") from exc
    if not isinstance(document, dict) or "version" not in document:
        raise LockError(f"{path}: not a cyberfw lock file (expected `version:` and `tools:`)")
    try:
        return ToolLock.model_validate(document)
    except ValidationError as exc:
        problems = "; ".join(
            f"{'.'.join(str(part) for part in err['loc']) or '<root>'}: {err['msg']}" for err in exc.errors()
        )
        raise LockError(f"{path}: {problems}") from exc


def _platform_rank(label: str) -> tuple[int, str]:
    labels = [mapping.label for mapping in SUPPORTED_PLATFORMS]
    return (labels.index(label) if label in labels else len(labels), label)


def dump_lock(lock: ToolLock) -> str:
    """The file's text: the header, then tools by name with their platforms in
    :data:`SUPPORTED_PLATFORMS` order — deterministic, so an unchanged lock
    rewrites byte-identical and a git diff shows only real changes."""
    document = {
        "version": lock.version,
        "tools": {
            name: {
                "repo": tool.repo,
                "tag": tool.tag,
                "assets": {
                    label: {"name": asset.name, "url": asset.url, "sha256": asset.sha256, "source": asset.source}
                    for label, asset in sorted(tool.assets.items(), key=lambda item: _platform_rank(item[0]))
                },
            }
            for name, tool in sorted(lock.tools.items())
        },
    }
    return _HEADER + yaml.safe_dump(document, sort_keys=False, allow_unicode=True, width=1000)


def write_lock(path: Path, lock: ToolLock) -> None:
    """Write ``lock`` to ``path`` atomically — a temp file, then ``os.replace`` —
    so an interrupted write never leaves a half-written lock behind."""
    tmp = path.with_name(path.name + ".tmp")
    try:
        tmp.write_text(dump_lock(lock), encoding="utf-8", newline="\n")
        os.replace(tmp, path)
    except OSError as exc:
        with contextlib.suppress(OSError):
            tmp.unlink(missing_ok=True)
        raise LockError(
            f"cannot write {path}: {exc} — run cyberfw from a workspace "
            "(a directory with registry.yaml) to change pins"
        ) from exc
```

_SHA256_HEX = re.compile(r"[0-9a-f]{64}")


def checksum_for(checksums_text: str | bytes, asset_name: str) -> str | None:
    """The SHA-256 a ``checksums.txt`` lists for exactly ``asset_name``, or ``None``.

    Lines are ``<sha256>  [*][dir/]<name>``. The name must equal ``asset_name`` —
    a suffix match would take ``mytool_linux_amd64.zip``'s line for
    ``tool_linux_amd64.zip``. An entry that is not a SHA-256 (a SHA-512 file,
    say) counts as no entry. Returned lowercase.
    """
    if isinstance(checksums_text, bytes):
        checksums_text = checksums_text.decode("utf-8", errors="replace")
    for line in checksums_text.splitlines():
        parts = line.strip().split(maxsplit=1)
        if len(parts) != 2:
            continue
        digest, name = parts
        if name.lstrip("*").rsplit("/", 1)[-1] != asset_name:
            continue
        digest = digest.lower()
        return digest if _SHA256_HEX.fullmatch(digest) else None
    return None

```python
class ReleaseSource(Protocol):
    """What resolving a lock entry needs from :class:`GitHubClient`."""

    def release(self, owner: str, repo: str, tag: str) -> GitHubRelease: ...

    def fetch_text(self, url: str) -> str: ...

    def download(self, url: str, destination: Path, *, expected_size: int | None = None) -> None: ...


def resolve_tool(client: ReleaseSource, spec: ToolSpec, *, work_dir: Path) -> LockedTool:
    """Pin ``spec`` to one release and record the SHA-256 of its asset on every
    supported platform.

    The release is the registry's ``version:`` tag when pinned, else the latest.
    :func:`select_asset` picks each platform's asset exactly as the installer
    would; a platform the release has no asset for is left out. A hash comes
    from the asset's API digest and/or the release's ``checksums.txt`` — both
    present and different is a :class:`LockError` — or, with neither, from
    downloading the asset into ``work_dir`` (removed again once hashed).
    """
    release = client.release(spec.repo_owner, spec.repo_name, spec.version)
    checksums = client.fetch_text(release.checksums_url) if release.checksums_url else ""
    hashed: dict[str, tuple[str, HashSource]] = {}
    assets: dict[str, LockedAsset] = {}
    for mapping in SUPPORTED_PLATFORMS:
        asset = select_asset(release, spec, mapping)
        if asset is None:
            continue
        if asset.name not in hashed:
            hashed[asset.name] = _hash_of(client, asset, checksums, work_dir)
        sha256, source = hashed[asset.name]
        try:
            assets[mapping.label] = LockedAsset(name=asset.name, url=asset.url, sha256=sha256, source=source)
        except ValidationError as exc:
            raise LockError(f"{spec.name}: cannot lock {asset.name}: {exc.errors()[0]['msg']}") from exc
    if not assets:
        raise LockError(
            f"{spec.name}: release {release.tag} of {spec.repo} has no asset for any supported platform"
        )
    return LockedTool(repo=spec.repo, tag=release.tag, assets=assets)


def _hash_of(
    client: ReleaseSource, asset: ReleaseAsset, checksums: str, work_dir: Path
) -> tuple[str, HashSource]:
    listed = checksum_for(checksums, asset.name) if checksums else None
    if asset.digest is not None and listed is not None and asset.digest != listed:
        raise LockError(
            f"digest and checksums.txt disagree for {asset.name} "
            f"(GitHub {asset.digest}, checksums.txt {listed}) — refusing to lock it"
        )
    if asset.digest is not None:
        return asset.digest, "digest"
    if listed is not None:
        return listed, "checksums"
    LOG.info("%s: no published digest or checksum — downloading it to hash it", asset.name)
    target = work_dir / asset.name
    try:
        client.download(asset.url, target, expected_size=asset.size or None)
        return sha256_hex(target), "download"
    finally:
        target.unlink(missing_ok=True)


def stale_reason(spec: ToolSpec, entry: LockedTool) -> str | None:
    """Why ``entry`` no longer satisfies ``spec``'s registry entry, or ``None``."""
    if entry.repo.lower() != spec.repo.lower():
        return f"repo changed (lock: {entry.repo}, registry: {spec.repo})"
    if spec.pinned_version is not None and entry.version != spec.pinned_version:
        return f"registry pins {spec.version}, lock has {entry.tag}"
    return None
```

        """Install one platform's entry of a locked release, verified against the lock.

        The archive's SHA-256 must equal the lock's *before* anything of the
        previous install is touched, so a replaced or corrupted download leaves
        the working tool in place. The downloaded archive is always removed.
        """
        tool_dir = self.tools_dir / spec.name
        archive_path = self.tools_dir / asset.name
        try:
            self.client.download(asset.url, archive_path)
            actual = sha256_hex(archive_path)
            if actual != asset.sha256:
                raise ChecksumError(
                    f"SHA-256 mismatch for {asset.name}: tools.lock has {asset.sha256}, got {actual}"
                )
            self._remove_existing_binary(spec)
            self._remove_stale_downloads(spec, keep=archive_path)
            self._reset_tool_dir(tool_dir)
            binary = self._extract(spec, archive_path, tool_dir)
        finally:
            archive_path.unlink(missing_ok=True)
        self._make_executable(binary)
        LOG.debug("%s: installed %s from %s -> %s", spec.name, version, asset.name, binary)
        return InstallResult(spec=spec, binary=binary.resolve(), version=version)

    def load_lock(self) -> ToolLock:
        """The lock on disk, or an empty one when there is no file yet."""
        return read_lock(self.lock_path) or ToolLock()

    def _resolve(self, spec: ToolSpec) -> LockedTool:
        with tempfile.TemporaryDirectory(prefix="cyberfw-lock-") as work:
            return resolve_tool(self.client, spec, work_dir=Path(work))

    def locked(self, name: str) -> LockedTool:
        """``name``'s entry in ``tools.lock``, adding it (and writing the lock) when
        the tool is not locked yet. An entry the registry no longer matches is a
        :class:`LockError`: installing never rewrites a pin — ``cyberfw lock`` does."""
        spec = self.spec(name)
        lock = self.load_lock()
        entry = lock.tools.get(name)
        if entry is None:
            entry = self._resolve(spec)
            write_lock(self.lock_path, ToolLock(tools={**lock.tools, name: entry}))
        reason = stale_reason(spec, entry)
        if reason is not None:
            raise LockError(f"{LOCK_NAME} is out of date for {name}: {reason} — run `cyberfw lock`")
        return entry

    def update_lock(self, names: list[str] | None = None, *, upgrade: bool = False) -> LockUpdate:
        """Bring ``tools.lock`` in line with the registry; write it if anything changed.

        Tools missing from the lock are added and stale entries (a changed
        ``repo`` / ``version:``) re-resolved; without ``names``, entries for tools
        gone from the registry (or now ``local``) are dropped. ``upgrade`` also
        re-resolves the entries that still match, moving them to the newest
        release the registry allows — but a release whose already-locked files
        changed under the same tag is refused and its entry kept. ``names``
        limits which tools are considered; an unknown one is a RegistryError.
        """
        lock = self.load_lock()
        tools = dict(lock.tools)
        downloadable = [name for name in self.registry.names() if not self.spec(name).is_local]
        changes: list[LockChange] = []
        if names is None:
            for gone in sorted(set(tools) - set(downloadable)):
                changes.append(LockChange(gone, tools.pop(gone).tag, None, "removed"))
        for name in downloadable if names is None else names:
            spec = self.spec(name)
            if spec.is_local:
                continue
            entry = tools.get(name)
            before = entry.tag if entry is not None else None
            stale = entry is not None and stale_reason(spec, entry) is not None
            if entry is not None and not stale and not upgrade:
                changes.append(LockChange(name, before, before, "unchanged", entry.sources))
                continue
            try:
                fresh = self._resolve(spec)
            except CyberfwError as exc:
                changes.append(LockChange(name, before, None, "failed", error=str(exc)))
                continue
            change: ChangeKind
            if entry is None:
                change = "added"
            elif stale:
                change = "re-resolved"
            elif fresh.tag != entry.tag:
                change = "upgraded"
            elif replaced := rehashed_platforms(entry, fresh):
                error = (
                    f"{entry.tag} changed upstream after it was locked ({', '.join(replaced)}); "
                    f"kept the locked files — to accept the new ones, remove {name} from "
                    f"{LOCK_NAME} and run `cyberfw lock {name}`"
                )
                changes.append(LockChange(name, before, before, "failed", error=error))
                continue
            else:
                change = "unchanged" if fresh == entry else "updated"
            tools[name] = fresh
            changes.append(LockChange(name, before, fresh.tag, change, fresh.sources))
        updated = ToolLock(tools=tools)
        written = updated != lock
        if written:
            write_lock(self.lock_path, updated)
        return LockUpdate(changes=changes, written=written, path=self.lock_path)

def _zip_bytes(members: dict[str, bytes]) -> bytes:
    buffer = io.BytesIO()
    with zipfile.ZipFile(buffer, "w", zipfile.ZIP_DEFLATED) as zf:
        for name, data in members.items():
            zf.writestr(name, data)
    return buffer.getvalue()


def _lying_zip_bytes(name: str, real_size: int, declared_size: int) -> bytes:
    """A DEFLATE member that inflates to ``real_size`` but whose headers claim ``declared_size``.

    This is the "header-forged decompression bomb" shape: the size check that sums
    ``file_size`` over the central directory sees only ``declared_size``.
    """
    data = bytearray(_zip_bytes({name: b"A" * real_size}))
    packed = struct.pack("<I", declared_size)
    data[22:26] = packed  # local file header: uncompressed size
    central = data.rfind(b"PK\x01\x02")
    data[central + 24 : central + 28] = packed  # central directory: uncompressed size
    return bytes(data)

@app.command("lock")
def lock_cmd(
    tools: Annotated[
        list[str] | None, typer.Argument(help="Tool names to lock; omit for every downloadable tool.")
    ] = None,
    upgrade: Annotated[
        bool, typer.Option("--upgrade", help="Also move tools to the newest release registry.yaml allows.")
    ] = False,
    token: Annotated[str | None, typer.Option("--token", envvar="CYBERFW_GITHUB_TOKEN",
                                             help="GitHub token to raise the rate limit.")] = None,
    verbose: VerboseOption = False,
) -> None:
    """Pin tools to exact releases and record each platform's SHA-256 in ``tools.lock``.

    Only what the registry no longer matches changes: missing tools are added,
    stale entries (a changed ``repo`` / ``version:``) re-resolved and removed
    tools dropped. ``--upgrade`` also moves tools to their newest allowed
    release; a release whose files changed under the same tag is refused.
    ``cyberfw init`` installs exactly what the lock pins — commit it.
    """
    settings, manager = _bootstrap(verbose=verbose)
    if token:
        settings = settings.model_copy(update={"github_token": token})
        manager = ToolManager(settings, manager.registry, manager.mapping, lock_path=manager.lock_path)
    for name in tools or []:
        if name not in manager.registry:
            console.print(f"[err]Unknown tool {name!r}.[/err] Known: {', '.join(manager.registry.names())}")
            manager.close()
            raise typer.Exit(2)
        if manager.spec(name).is_local:
            console.print(f"[muted]{name} is a local tool — nothing to lock; skipping.[/muted]")
    console.print(Text.assemble(("Locking tools into ", "info"), (str(manager.lock_path), "tool")))
    try:
        update = manager.update_lock(tools or None, upgrade=upgrade)
    except CyberfwError as exc:
        console.print(f"[err]{exc}[/err]")
        raise typer.Exit(1) from exc
    finally:
        manager.close()
    if update.changes:
        console.print(_lock_table(update.changes))
    if update.written:
        console.print(
            f"[ok]Wrote {update.path.name}[/ok] — commit it so every machine installs the same, verified tools."
        )
    else:
        console.print(f"[muted]{update.path.name} unchanged.[/muted]")
    if update.failed:
        raise typer.Exit(1)
